# Python Basics Repository

This repository contains beginner-to-intermediate level Python programs covering fundamental programming concepts and Object-Oriented Programming (OOP).  
The repository is organized topic-wise to provide structured learning and hands-on practice for Python programming.

---

## Repository Overview

The project includes Python programs created during learning and practice sessions.  
Each file focuses on a specific concept and contains examples for better understanding of Python fundamentals and core programming principles.

---

## Topics Covered

- Print Statements and Basic Operations
- Strings
- Conditional Statements
- Lists and Tuples
- Dictionaries and Sets
- Loops (`for` and `while`)
- Functions
- File Handling
- Object-Oriented Programming (OOP)

## How to Run

1. Clone the repository

```bash
git clone https://github.com/AyushBhor04/Python-Basics.git
```

2. Open the project folder in VS Code

3. Run any Python file

```bash
python filename.py
```

Example:

```bash
python video_1.py
```
